💡 DICAS IMPORTANTES
================================================================================

1. Sempre execute ./scripts/deploy-psi.sh --dry-run ANTES de --production

2. Verifique nginx.conf com: sudo nginx -t

3. Monitore logs em tempo real:
   tail -f /var/log/nginx/psi-frontend-access.log
   tail -f /var/log/nginx/psi-frontend-error.log

4. Teste certificado SSL:
   openssl s_client -connect psi.hfnew.com.br:443 -showcerts

5. Rollback rápido:
   git revert [commit-hash] && npm run build && sudo systemctl reload nginx

6. Backup está em:
   /opt/hfnew-psi/backups/

7. Recuperar backup:
   cp -r /opt/hfnew-psi/backups/[backup-dir]/dist-* /opt/hfnew-psi/frontend/dist
